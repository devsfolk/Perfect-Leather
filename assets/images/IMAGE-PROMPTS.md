# Perfect Leather — Original Image Generation Guide

This guide replaces the current third-party image URLs with a coherent original image set. Generate each image with the exact filename below and save it in `assets/images/`.

## Global art direction — apply to EVERY prompt

Photorealistic commercial photography for one believable leather-goods workshop and studio in Karachi, Pakistan. Warm neutral palette: espresso brown, walnut, cognac, tan, muted beige and charcoal. Natural full-grain leather with visible pores, subtle irregularities, realistic folds, true-to-life stitching and believable hardware. A consistent practical studio: warm beige plaster wall, dark walnut workbench, neutral linen or kraft paper props, soft daylight entering from camera-left, gentle real contact shadows. Shot as if by a professional product photographer on a full-frame camera with a 50mm or 85mm lens; realistic depth of field, restrained color grading, sharp product details, no over-processing. Premium but authentic, not an unreal luxury showroom. No visible people unless a prompt specifically asks for hands. Do not show any existing brand, trademark, monogram, readable text, fake labels, watermark, price tag, logo or packaging. Avoid CGI, 3D render, plastic-looking leather, perfect mirrored symmetry, oversaturated colors, floating objects, impossible seams, extra straps/buckles, warped geometry and repeated duplicate products.

For all product images, keep the product fully visible and physically plausible, with clean framing and enough margin around it. Use a 4:5 portrait crop for product cards unless your image tool only supports square; use 16:9 for hero/banner images. Generate images separately, one file per prompt.

## How to save and connect images

1. Create this folder: `assets/images/`.
2. Generate each image separately using its prompt above. Save it with the exact filename and `.jpg` extension listed here. If your image tool exports PNG or WebP instead, either convert it to JPG or update the matching code path to the actual extension.
3. Use 1600–2000 px wide for the hero and 1000–1400 px on the long side for product images. Compress images for web; aim for roughly 200–450 KB per image when quality permits.
4. Replace remote `https://images.unsplash.com/...` image paths in the HTML with local paths such as `assets/images/wallet-classic.jpg`.
5. Also update the image URLs inside `data-lightbox-src` attributes in `gallery.html`, the Open Graph `og:image` meta tags in all HTML pages, and the hero image backgrounds in `styles.css` (search for `images.unsplash.com`). Otherwise the lightbox, sharing preview or hero background may still use the old remote image.
6. Keep the existing logo files `assets/perfect-leather-logo.svg` and `assets/favicon.svg`; these are brand assets, not product photographs.
7. After replacement, search the project for `unsplash.com`. There should be no matches if all external photos have been replaced.

## Realism and truthfulness check

- Review every image at full size. Regenerate anything with melted seams, impossible straps, distorted hands, repeated texture, fake text, brand logos or implausible hardware.
- Use the same approved studio/background reference image when your generator supports reference images. Keep the lighting direction and color grading fixed.
- These generated photographs are visual marketing assets, not proof of the company's actual premises, staff, products or manufacturing steps. Do not caption illustrative generated scenes as documentary evidence of verified company operations.
