# Perfect Leather — Static Website

A responsive multi-page business website built with plain HTML, CSS, and JavaScript. No build step, paid backend, or package manager is required.

## Pages
- `index.html` — Home
- `about.html` — About Perfect Leather
- `products.html` — Product catalogue with category filters
- `handmade.html` — Handmade leather details
- `manufacturing.html` — General leather-making process overview
- `gallery.html` — Responsive gallery with image lightbox
- `contact.html` — Supplied contact details
- `404.html` — Not-found page

## Run locally
Open `index.html` in a browser. The site does not require a server.

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository (keep `index.html` at the root).
2. Commit and push the files.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your branch (commonly `main`) and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown there.

For a custom domain, configure DNS at the domain provider and add the domain in GitHub Pages settings. Confirm the intended hosting setup before changing DNS records.

## Images and fonts
The site uses local images located in `assets/images/` adhering to `IMAGE-PROMPTS.md`. All photography is fully self-contained within the repository. Images are illustrative and are not verified photographs of Perfect Leather's own products or facilities.

## Accuracy notes
The manufacturing page describes general industry processes and does not claim Perfect Leather uses every listed method. Product styles are illustrative; no company prices, stock availability, certifications, awards, testimonials, or production capacity are invented. A contact form is not included because no form-processing endpoint was supplied. The map link searches the supplied address rather than claiming a verified pin. The telephone link uses the number exactly as supplied.
